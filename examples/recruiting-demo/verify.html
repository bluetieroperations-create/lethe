Verify a deletion certificate

Paste a certificate and the operator's published public key. Everything runs in this page — nothing is uploaded. A certificate that vouches for itself proves nothing, so the key must come from the operator out of band, not from the certificate.

NOT CHECKED Paste a certificate and a public key, then press Verify.
    All four checks must pass. The signature alone is not enough: a certificate carries the key that signed it, so checking it against itself only proves internal consistency. Pinning the operator's published key is what makes the result mean anything. This page requires a browser with Ed25519 in the Web Crypto API (Chrome 137+, Firefox 129+, Safari 17+).
